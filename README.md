# Retail-SQL-Analysis

📌 Project Overview
This project focuses on analyzing retail sales data using SQL queries.  
The objective is to extract meaningful business insights from sales transactions and improve decision-making using data analysis techniques.


🎯 Project Objectives
- Analyze sales performance
- Identify top-selling products
- Find high revenue-generating categories
- Analyze customer purchasing behavior
- Calculate monthly and yearly sales trends
- Improve business decision-making using SQL


🛠️ Tools & Technologies Used
- SQL
- MySQL / PostgreSQL
- Excel / CSV Dataset
- Data Analysis


📂 Dataset Information
The dataset contains retail transaction details such as:
- Invoice Number
- Customer ID
- Product Description
- Quantity
- Unit Price
- Total Revenue
- Country
- Invoice Date


📊 SQL Analysis Performed

Basic Queries
- Total number of orders
- Total sales revenue
- Distinct customer count

Intermediate Queries
- Top-selling products
- Revenue by country
- Monthly sales trend
- Average order value

 Advanced Queries
- Customer segmentation
- Best-performing categories
- Repeat customer analysis
- Revenue contribution analysis


📈 Key Insights
- Certain products generate maximum revenue.
- Repeat customers contribute significantly to total sales.
- Seasonal trends impact monthly sales.
- Some countries show higher purchasing activity.


📁 Project Files
- Retail Project SQL.sql

- README.md


🚀 How to Use
1. Download the SQL file
2. Open MySQL / PostgreSQL
3. Import the dataset
4. Run SQL queries step by step
5. Analyze business insights
